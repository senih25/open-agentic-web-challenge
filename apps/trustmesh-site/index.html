PRIVACY MODEL

Private by default.
Specific by permission.

TrustMesh is built around explicit data boundaries. A valid agent network is not automatically a trusted agent. Every external origin is reviewed, every request is scoped and every result is treated as untrusted until validated.

⌑No shared browser sessionCredentials, cookies and local browser data never belong in a peer request.
↗One origin at a timeEvery new external website needs its own approval.
▤Redacted evidenceThe receipt records disclosure decisions, not private field values.
